# Bed Wars Online

Testar no seu computador:
    npm install
    npm start
Abra http://localhost:3000 em duas abas, entre na mesma sala e clique em "Iniciar partida".

Publicar no Render: suba estes arquivos para um repositório no GitHub, crie um Web Service no Render
apontando para ele (Build: npm install · Start: npm start · Plano: Free) e abra a URL que o Render gerar.
